Support only the current RustClipSync protocol. Remove the obsolete SyncClipboard transport, SignalR path, fallback watcher and protocol selector. The marketplace-reported sensitive plaintext history path is removed along with that transport. HTTP endpoints now use `/api/...`; encrypted state filenames, keyring identifiers and device identity remain unchanged. Existing history is not erased.

Current synchronization, sensitive inbox, history and direction controls remain available. Native binaries are rebuilt and byte-compared before publication. Marketplace maintainer review remains pending; this release has not been automatically deployed to the active desktop.
